# E-commerce Add to Cart

A simple e-commerce shopping cart project built with HTML, CSS, and vanilla JavaScript.

## Features

- Display products dynamically
- Add products to the cart
- Increase or decrease product quantity
- Remove products from the cart
- Calculate subtotal and total items
- Persist cart data using `localStorage`
- Responsive layout for different screen sizes

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Start the project using a local development server, such as the **Live Server** extension.
4. Open the application in your browser.

## How It Works

Products are rendered on the page using JavaScript. When a user adds an item to the cart, the cart state is updated and saved in the browser's `localStorage`, allowing the cart to remain available after refreshing the page.
